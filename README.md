# IPAX — Two Pathways to Funding

A single, self-contained HTML page presenting two pathways to funding **Open IPAX** — a philanthropic frame and a for-profit frame for a visually accessible digital world.

- **`index.html`** — the whole page in one file. All four mockup images are embedded as data URIs, so there are no external asset dependencies. Open it directly in any browser.
- Each mockup is clickable to open in a full-size zoom overlay.

Styling (Poppins, cream paper, palette) follows the [Provoke concepts](https://brandonschauer.github.io/provoke-concepts/) reference.
